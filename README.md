# LA OMUT · Учёт работы цеха

Приложение для телефона (PWA): швеи вносят, что сшили, и сразу видят свой заработок за период. Руководитель видит свод по всем, правит прайс и команду.

- **Сайт** — GitHub Pages (бесплатно).
- **Хранилище** — ваша Google Таблица (листы «Записи», «Прайс», «Сотрудники»).
- **Связка** — Google Apps Script внутри таблицы, он работает как сервер.

```
Телефон швеи ──► сайт на GitHub Pages ──► Apps Script ──► Google Таблица
```

Отдельные таблицы для каждой швеи и Google Форма больше не нужны.

---

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | Всё приложение. Вверху блок `CONFIG`, туда вставляется ссылка API |
| `manifest.webmanifest`, `sw.js`, `icons/` | Нужны, чтобы приложение ставилось на телефон и работало без интернета |
| `apps-script/Code.gs` | Код «сервера» для Google Таблицы |

## Установка (≈15 минут)

### 1. Подключить таблицу

1. Откройте **главную** таблицу (где «Журнал швей», «Прайс швей», «Ответы на форму (1)»).
2. **Расширения → Apps Script**.
3. Удалите всё в `Code.gs` и вставьте содержимое `apps-script/Code.gs`. Сохраните.
4. Вверху выберите функцию **`setup`** → **Выполнить** → разрешите доступ к своей таблице.
   Скрипт создаст три листа и перенесёт старые данные. Старые листы останутся на месте.
   - **Прайс** — копия «Прайс швей».
   - **Сотрудники** — швеи из «Журнала швей» и «Руководитель». Каждому выдан случайный PIN.
   - **Записи** — все ответы из формы и журнала.
5. Откройте лист **«Сотрудники»** и посмотрите PIN-коды. Их можно поменять прямо там (4 цифры).

### 2. Опубликовать API

1. В Apps Script: **Развернуть → Новое развёртывание**.
2. Тип: **Веб-приложение**.
   - Выполнять от имени: **Я**
   - У кого есть доступ: **Все**
3. **Развернуть** и скопируйте ссылку, которая заканчивается на `/exec`.

> Если потом поменяете `Code.gs`, сделайте **Развернуть → Управление развёртываниями → ✏️ → Версия: новая**. Тогда ссылка останется прежней.

### 3. Вставить ссылку в приложение

В `index.html` найдите:

```js
API_URL: '',
```

и вставьте свою ссылку:

```js
API_URL: 'https://script.google.com/macros/s/XXXXXXXX/exec',
```

Пока ссылка пустая, приложение работает в **демо-режиме** на тестовых данных.

### 4. Выложить на GitHub Pages

1. Зайдите на github.com → **New repository**, например `laomut`. Можно сделать **Private**, если у вас GitHub Pro; на бесплатном аккаунте Pages работает только для Public.
2. **Add file → Upload files** → перетащите всё содержимое папки: `index.html`, `manifest.webmanifest`, `sw.js`, папку `icons`. Папку `apps-script` загружать не нужно. → **Commit**.
3. **Settings → Pages → Branch: main / (root) → Save**.
4. Через минуту сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/laomut/`.

### 5. Установить на телефоны

- **iPhone**: открыть ссылку в Safari → «Поделиться» → **«На экран Домой»**.
- **Android**: открыть в Chrome → меню ⋮ → **«Установить приложение»**.

Отправьте девочкам ссылку и их PIN. Вход один раз, дальше телефон помнит.

## Как пользоваться

**Швея**
1. «Внести» → дата (сегодня / вчера / другой день) → заказ → нажать на изделие → количество → «Добавить».
2. Можно набрать несколько изделий и отправить разом.
3. «Мои работы» — всё, что внесено за период, и сумма. Ошибочную запись можно удалить в течение 2 дней.
4. Нет интернета? Запись сохранится на телефоне и отправится сама, когда связь появится.

**Руководитель** (вход под «Руководитель»)
- **Свод**: кому сколько платить за период, кто что шил. Кнопка «Скачать таблицу (CSV)» откроется в Excel.
- **Внести**: внести работу за любую швею.
- **Записи**: все записи с фильтром по швее, можно удалить любую.
- **Прайс**: поменять цену, добавить изделие, скрыть изделие. Старые записи сохраняют цену, по которой были внесены, так что прошлые зарплаты не «поплывут».
- **Команда**: добавить или отключить сотрудницу, сменить PIN.

Период считается по половинам месяца: 1–15 и 16–конец. Чтобы считать целым месяцем, в `index.html` поставьте `PERIOD: 'month'`.

И конечно, вы по-прежнему можете открыть Google Таблицу и смотреть или фильтровать лист «Записи» как обычно.

## Безопасность — честно

- PIN защищает от случайностей и любопытства, но это не банковская защита. После 5 неверных попыток вход блокируется на 10 минут.
- PIN-коды видны только на листе «Сотрудники» в вашей таблице. Швеи их не видят и чужие записи не видят.
- Саму таблицу никому, кроме себя, не открывайте: приложению это не нужно.
- Ссылку `/exec` не публикуйте в открытом доступе. Без PIN по ней всё равно ничего не получить, кроме списка имён.

## Если что-то не работает

| Симптом | Что сделать |
|---|---|
| «Сервер ответил с ошибкой» | Проверьте, что в развёртывании доступ «Все» и ссылка заканчивается на `/exec` |
| Изменила `Code.gs`, а ничего не поменялось | Развернуть → Управление развёртываниями → новая версия |
| Поменяла `index.html`, а на телефоне старое | Закройте и откройте приложение. Если не помогло, в `sw.js` поменяйте `laomut-v1` на `laomut-v2` |
| Даты сдвигаются на день | Файл → Настройки таблицы → Часовой пояс: ваш |
